# MAHC — Multi-Agent Hierarchical Consensus (HELIOS Novelty)

## Mathematical Definition
Vote(v) ∈ [0,1] with uncertainty u(v)
Hierarchical aggregation: weighted by confidence + entropy regularization

## Key Components
- Uncertainty propagation (Gaussian)
- Confidence normalization
- Disagreement threshold → escalation to human/SRE
- Fallback: statistical baseline
