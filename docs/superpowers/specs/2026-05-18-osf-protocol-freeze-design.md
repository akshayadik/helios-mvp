## Architecture Overview

```
bin/verify_osf_freeze.py            — generate + verify CLI (two modes)
research/
└── osf/
    ├── seeds.json                  — all seeds from seed_register.md
    ├── prompt_sha.json             — prompt version + SHA from prompt_version_registry
    ├── thresholds.json             — calibrated params (D-pipe + G-pipe + PPR gates)
    ├── variant_hashes.json         — 8 confirmatory variant config hashes
    ├── analysis_plan.json          — hypotheses, statistical tests, alpha, Holm table
    ├── corpus_manifest.json        — exploratory corpus (20 incidents); confirmatory placeholder
    └── manifest_sig.txt            — SHA-256 of concatenated artefacts (tamper-guard)
research/
└── ablation_notebook.ipynb         — L0–L3 pipeline matrix + variant flag matrix
```

All six JSON files are **generated by script only** (never hand-written). `manifest_sig.txt` is computed over them.

## `bin/verify_osf_freeze.py` — Two Modes

### `--generate` mode

Reads from live sources and writes all six JSON files, then computes `manifest_sig.txt`:

| Source | Output file |
|---|---|
| `docs/tracking/seed_register.md` | `research/osf/seeds.json` |
| `docs/tracking/prompt_version_registry.md` + `lpipe_config.py` | `research/osf/prompt_sha.json` |
| `data/calibrated_params.json` + `dpipe_config.py` + `gpipe_config.py` | `research/osf/thresholds.json` |
| `docs/tracking/vcl_manifest_tracking.md` | `research/osf/variant_hashes.json` |
| `docs/tracking/hypothesis_variant_metric_mapping.md` | `research/osf/analysis_plan.json` |
| `data/snapshot_registry.jsonl` | `research/osf/corpus_manifest.json` |
| SHA-256 of concatenated artefacts (alphabetical) | `research/osf/manifest_sig.txt` |

Concatenation order for `manifest_sig.txt` is deterministic: alphabetical by filename.

### `--verify` mode (used in CI)

Re-reads live sources, regenerates in memory, diffs against files on disk:
- Any content mismatch → non-zero exit + printed diff
- `manifest_sig.txt` mismatch → non-zero exit
- All match → exit 0

CI step added to `ci.yml`:
```yaml
- name: Verify OSF freeze
  run: |
    set -a; source .env; set +a
    poetry run python bin/verify_osf_freeze.py --verify
```

**Zero hand-written JSONs rule:** `--verify` will detect any JSON that was edited by hand rather than generated. No manual edits to any file under `research/osf/`.

### Line-ending and serialisation discipline

**LF normalization (CRLF safety):** All file I/O in `verify_osf_freeze.py` must use binary mode with explicit LF normalisation. Using text mode (`open(..., "r")`) on Windows produces CRLF line endings that change the SHA-256 hash relative to the ubuntu-22.04 CI runner. Use binary mode throughout:

```python
# Write
path.write_bytes(content.encode("utf-8").replace(b"\r\n", b"\n"))

# Read for hashing and diffing
raw = path.read_bytes().replace(b"\r\n", b"\n")
```

**JSON serialisation via `canonical_json`:** All JSON output must be produced by `helios.vcl.utils.canonical_json`, never raw `json.dumps()`. This ensures sorted keys, deterministic float precision (`round(o, 6)`), and no unexpected whitespace variance across platforms. The canonical serialisation is the source of truth for the manifest hash:

```python
from helios.vcl.utils import canonical_json

content = canonical_json(data_dict) + "\n"  # single trailing newline
```

### `manifest_sig.txt`

SHA-256 of concatenated JSON file contents in alphabetical filename order:

```

  analysis_plan.json  ||
  corpus_manifest.json  ||
  prompt_sha.json  ||
  seeds.json  ||
  thresholds.json  ||
  variant_hashes.json
)
```

Written as a single 64-char hex string. `--verify` recomputes and asserts equality.

## Pre-registration Document (`research/osf/preregistration.md`)

Human-authored document summarising the frozen artefacts for examiner and OSF deposit readability. Required sections:

| Section | Content |
|---|---|
| Overview | Research question, DSR methodology, HELIOS artefact description |
| Hypotheses | A-H1..A-H8 with rank order, primary metric, and alpha per Holm table |
| Variants | 8 VCL variants, flag matrix (13 boolean flags × 8 variants), hypothesis mapping |
| Statistical Analysis Plan | Wilcoxon signed-rank (one-sided), Holm–Bonferroni table, effect size commitment |
| Corpus | Exploratory calibration (20 OTEL Demo) + confirmatory placeholder (174 AIOpsLab, deferred) |
| Frozen Artefacts | SHA fingerprints of all 6 JSON files + `manifest_sig.txt` (integrity anchor) |
| Deviation Summary | Narrative of all deviation log entries at freeze time, sourced from `deviation_log.md` |
| OSF Deposit DOI | `[to be added post-upload]` placeholder |

**No TBD sections permitted at exit.** The Deviation Summary must reference every entry in the deviation log at the time of freeze. The frozen artefact SHA table must be populated from actual computed values (generated by `--generate`, not placeholders).

## Ablation Notebook (`research/ablation_notebook.ipynb`)

A Jupyter notebook. No new computation — all values sourced from frozen OSF artefacts and tracking docs.

Required cells:

| Section | Content |
|---|---|
| L0 — VCL | Flag matrix table (all 8 variants × 14 flags), loaded from `variant_hashes.json` |
| L1 — D-pipe Calibration | LOO-CV results table, calibration parameter table, loaded from `thresholds.json` |
| L2 — G-pipe | PPR disagreement threshold, entry gate calibration results, loaded from `thresholds.json`; note A-H6 sentinel filter requirement |
| L3 — L-pipe | Prompt version, model, Protocol A settings, loaded from `prompt_sha.json` |

**Import constraint — mandatory:** Notebook code cells must **not** import from `helios.pipelines.*` or `helios.orchestrator.*`. All data must be loaded from the frozen JSON artefacts under `research/osf/` using standard file reads only:

```python
import json
from pathlib import Path

OSF_DIR = Path("research/osf")

with open(OSF_DIR / "thresholds.json") as f:
    thresholds = json.load(f)

with open(OSF_DIR / "variant_hashes.json") as f:
    variant_hashes = json.load(f)
```

Importing from `helios.pipelines` or `helios.orchestrator` would introduce a runtime dependency on the installed HELIOS package — making the notebook non-executable in environments where the package is not installed (e.g., OSF reviewer machines, Binder). The notebook must be fully self-contained given only the `research/osf/*.json` files and standard library plus `pandas`/`json`.

**Render requirement:** `jupyter nbconvert --execute research/ablation_notebook.ipynb` must complete without error and without requiring Ollama to be running. L3 section displays config values only — no live inference.
